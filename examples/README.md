# Small inspection examples

The source-staging helper populates these from the working project when available:

- `map/valmet_map.yaml` and its PGM: the current floor map, for inspection.
- `manual_annotations.json`: the supplied manual positions and boxes, with machine-specific absolute paths redacted in this example copy.
- `query_images/`: add a few representative component images yourself.

These examples are not a complete runtime bundle. The annotation JSON alone does not contain its referenced images or point clouds. Keep the original files in the separate runtime archive. Confirm permission before publishing scene-derived data.
