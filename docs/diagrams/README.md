# Architecture figures

The three numbered PNG files are cropped panels from an AI-generated conceptual overview. They are used in the repository README. `pipeline-overview.png` keeps the combined illustration.

The matching SVG files are separate, editable block-diagram versions with live text and vector shapes. Use them in slides when you need to change labels or reflow content. No fonts are embedded or distributed. These figures are explanatory graphics, not screenshots or measured results.
